# 우리술 — 출시 전 점검

현재 홈페이지는 카페24의 진열 상품을 보여주지만 `STORE_LIVE`가 `true`가 아닌 동안은
시연 모드로 동작하며 구매 버튼을 표시하지 않습니다. 샘플상품에 주문이 발생하지 않도록
운영 준비 중에는 이 값을 설정하지 마세요.

## 연결 및 시연

- 카페24 연결: `/admin/cafe24`에서 관리자 로그인 후 OAuth 승인.
- 준비 상태: `/admin/launch-check` (같은 관리자 인증). 비밀키 값은 표시하지 않습니다.
- 쿠팡 주문 시연: `/admin/coupang/orders`. Wing 키를 넣기 전에는 명확히 표시된
  가상 주문 1건만 반환합니다. 고객정보는 사용하지 않습니다.
- Wing 계정이 준비되면 Render 환경변수에 `COUPANG_VENDOR_ID`,
  `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`를 설정합니다. 이후 주문 확인 화면은
  최근 60분의 결제완료(`ACCEPT`) 발주서 메타데이터를 읽기 전용으로 조회합니다.
  고객 이름, 연락처, 배송지는 이 화면에 저장하거나 반환하지 않습니다.
- 카페24 상품번호와 쿠팡 상품 페이지 연결은 `COUPANG_PRODUCT_URLS`에 JSON으로
  설정합니다. 예: `{"123":"https://www.coupang.com/vp/products/456"}`.
  실제 쿠팡 상품 URL이 없으면 해당 버튼은 나오지 않습니다.

## 출시 전 확인

1. 샘플상품을 실제 상품으로 교체하고 상품명·가격·사진·판매 정보를 검수합니다.
2. 쿠팡 Wing 판매자 등록 및 상품 등록 가능 여부를 확인하고 API 키를 발급합니다.
   쿠팡 API는 판매자 인증 및 등록 IP가 필요하며 공식 테스트 환경이 없습니다.
3. 출고, 반품, 성인인증, 전통주 통신판매 자격과 각 채널의 승인 상태를 확인합니다.
4. 실제 쿠팡 주문을 대상으로 주문 조회를 확인한 후에만 `STORE_LIVE=true`를
   적용합니다. 주문/재고 자동 동기화와 배송 처리 기능은 아직 구현되지 않았습니다.
